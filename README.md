# Machine Learning for Inventory Demand Forecasting Across Retail Demand Patterns

## Project Overview

This repository contains the ongoing work for my Master's thesis in Data Science and Advanced Analytics at NOVA IMS, Universidade NOVA de Lisboa.

The research focuses on retail demand forecasting using statistical and machine learning methods. Different retail products exhibit different demand patterns, making it challenging for a single forecasting model to perform equally well across all products.

The project aims to investigate whether demand-pattern-aware model selection can improve forecasting accuracy and support better inventory decisions.

## Research Objectives

1. Analyze and classify retail demand patterns.
2. Compare statistical and machine learning forecasting methods.
3. Investigate demand-pattern-aware model selection.
4. Evaluate forecasting performance using appropriate metrics.
5. Assess the impact of forecasting on inventory management.

## Dataset

**M5 Forecasting Dataset (Walmart)**

The dataset contains historical retail sales information, product and store identifiers, calendar events, and selling prices.

## Planned Methodology

1. Data collection and preprocessing
2. Exploratory Data Analysis (EDA)
3. Demand pattern classification using ADI and CV²
4. Statistical baseline forecasting
5. Machine learning model development
6. Model evaluation using MASE and RMSE
7. Demand-pattern-aware model comparison and selection
8. Inventory simulation to evaluate stockouts, service levels, and inventory costs
